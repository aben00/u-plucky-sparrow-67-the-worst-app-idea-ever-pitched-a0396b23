One original one-sentence pitch for the worst, most useless app imaginable,
written by a program. The pitch: PebbleCloud, a $10-a-month app that photographs
every pebble you own, backs them up to the cloud, and lets you admire rocks
already sitting in your garden from anywhere on Earth. A founder who means
every word, solving a problem nobody has with technology nobody asked for.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22) writes the pitch deterministically to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt`), self-checks the gate (one sentence,
1–240 characters by code-point count, no control characters, no doubled
spaces, no edge whitespace), reads it back with strict UTF-8 decoding and
verifies it byte-for-byte, including the byte length.
